排序算法：从 O(n²) 到基数排序

代码风格和 上一篇一致，大数组开成全局静态的。 所有排序都用对数器测过：2 万组随机数组，长度 0～60，值域 −1000～1000（故意带负数，基数排序最容易在这里出错）， 结果和 Arrays.sort 逐个比对。

O(n²) 的三个：选择、冒泡、插入

选择排序每轮找最小值放到前面，冒泡排序每轮把最大值换到后面，插入排序把新来的数往前插进已经有序的部分。 三个都是 O(n²)、O(1) 额外空间，只有选择排序不稳定。笔试里很少直接用，但插入排序值得记住： 数组本来就接近有序时它几乎是 O(n)，数据量很小时常数也最低，JDK 的 Arrays.sort 在小区间上同样会切到插入排序。 

// 插入排序：把 arr[i] 往前插到已经有序的 [0, i-1] 里
public static void insertionSort(int[] arr) {
    for (int i = 1; i < arr.length; i++) {
        for (int j = i - 1; j >= 0 && arr[j] > arr[j + 1]; j--) {
            swap(arr, j, j + 1);
        }
    }
}

归并排序

先让左右两半各自有序，再用双指针合并。合并需要一块辅助空间，这里开成全局的 help，整个排序只申请一次。 左右相等时先拿左边的数，相同的值就保持原来的相对顺序，这是归并排序稳定的原因，改成 < 就不稳定了。 

public static int MAXN = 100001;
public static int[] help = new int[MAXN];   // 全局辅助数组，只申请一次

// 让 arr[l..r] 有序
public static void mergeSort(int[] arr, int l, int r) {
    if (l >= r) {
        return;
    }
    int m = l + ((r - l) >> 1);
    mergeSort(arr, l, m);
    mergeSort(arr, m + 1, r);
    merge(arr, l, m, r);
}

// arr[l..m] 和 arr[m+1..r] 各自有序，合并成整体有序
public static void merge(int[] arr, int l, int m, int r) {
    int i = l, a = l, b = m + 1;
    while (a <= m && b <= r) {
        // 相等时先拿左边，这就是归并排序稳定的原因
        help[i++] = arr[a] <= arr[b] ? arr[a++] : arr[b++];
    }
    while (a <= m) help[i++] = arr[a++];
    while (b <= r) help[i++] = arr[b++];
    for (i = l; i <= r; i++) {
        arr[i] = help[i];
    }
}

归并分治

归并排序真正值钱的是它的分治结构。如果一个问题的答案能拆成「左半内部 + 右半内部 + 跨越左右」三部分， 并且在左右两半各自有序时跨越部分能用双指针线性算出来，就可以借归并排序的递归一起算完，总复杂度还是 O(n log n)。 逆序对是最标准的例子：对右半的每个 arr[j]，左半里比它大的数都排在指针 i 之后，个数就是 m - i + 1。 计数要在 merge 之前做，合并之后左右的边界就没了。 

// 归并分治：统计逆序对 (i < j 且 arr[i] > arr[j]) 的数量
// 答案 = 左半内部 + 右半内部 + 跨左右的；跨左右的部分在两边都有序时用双指针 O(n) 算出
public static long inversions(int[] arr, int l, int r) {
    if (l >= r) {
        return 0;
    }
    int m = l + ((r - l) >> 1);
    long ans = inversions(arr, l, m) + inversions(arr, m + 1, r);
    // 对右边每个 arr[j]，数左边有多少个数比它大
    for (int i = l, j = m + 1; j <= r; j++) {
        while (i <= m && arr[i] <= arr[j]) {
            i++;
        }
        ans += m - i + 1;
    }
    merge(arr, l, m, r);
    return ans;
}

随机快速排序

固定拿第一个数当划分值，遇到已经有序的数组每次只能切掉一个数，退化成 O(n²)。随机选划分值之后， 复杂度要按期望算，是 O(n log n)，最坏情况出现的概率可以忽略。 划分用荷兰国旗的三段式：小于 x、等于 x、大于 x。等于 x 的一整段不再参与递归，数组里重复值很多时比两段式快得多。

有一处容易写错：first 和 last 是全局变量，左半边递归会把它们改掉， 所以调用 partition 之后要先存进局部变量，再去递归。 

public static Random rand = new Random();
public static int first, last;   // partition 之后 == x 的区域 [first, last]

// 随机快排：随机选划分值 + 荷兰国旗划分（< x | == x | > x）
public static void quickSort(int[] arr, int l, int r) {
    if (l >= r) {
        return;
    }
    int x = arr[l + rand.nextInt(r - l + 1)];
    partition(arr, l, r, x);
    int left = first, right = last;   // 递归会改 first / last，先记下来
    quickSort(arr, l, left - 1);
    quickSort(arr, right + 1, r);
}

public static void partition(int[] arr, int l, int r, int x) {
    first = l;
    last = r;
    int i = l;
    while (i <= last) {
        if (arr[i] < x) {
            swap(arr, first++, i++);
        } else if (arr[i] > x) {
            swap(arr, i, last--);   // 换过来的数还没看过，i 不动
        } else {
            i++;
        }
    }
}

随机选择：第 K 大

找第 K 大没必要把整个数组排好。同样随机选划分值做一次 partition，目标下标落在哪一段，就只去那一段继续找。 每次只走一边，期望复杂度是 O(n)。写成循环也不需要递归栈。 

// 随机选择：返回 arr 排好序后下标为 k 的数，期望 O(n)
// 第 k 大 = 下标 n - k；只往一边递归，所以比完整排序快
public static int randomizedSelect(int[] arr, int k) {
    int l = 0, r = arr.length - 1;
    while (l <= r) {
        partition(arr, l, r, arr[l + rand.nextInt(r - l + 1)]);
        if (k < first) {
            r = first - 1;
        } else if (k > last) {
            l = last + 1;
        } else {
            return arr[k];
        }
    }
    return -1;
}

堆排序

堆只要两个动作：heapInsert 让一个数往上走，heapify 让一个数往下沉。 建堆有两种做法，从顶到底依次 heapInsert 是 O(n log n)；从最后一个数往前依次 heapify 是 O(n)， 因为大部分节点在底层，往下沉不了几步。建好大根堆之后，反复把堆顶换到末尾、堆的大小减一、再 heapify。 整体 O(n log n)，额外空间 O(1)，不稳定。 

// i 位置的数往上看，比父亲大就交换（大根堆）
public static void heapInsert(int[] arr, int i) {
    while (arr[i] > arr[(i - 1) / 2]) {
        swap(arr, i, (i - 1) / 2);
        i = (i - 1) / 2;
    }
}

// i 位置的数往下看，和较大的孩子比，比孩子小就下沉；堆的大小是 size
public static void heapify(int[] arr, int i, int size) {
    int l = i * 2 + 1;
    while (l < size) {
        int best = l + 1 < size && arr[l + 1] > arr[l] ? l + 1 : l;
        best = arr[best] > arr[i] ? best : i;
        if (best == i) {
            break;
        }
        swap(arr, best, i);
        i = best;
        l = i * 2 + 1;
    }
}

// 从底到顶建堆 O(n)，然后反复把堆顶（最大值）换到末尾
public static void heapSort(int[] arr) {
    int n = arr.length;
    for (int i = n - 1; i >= 0; i--) {
        heapify(arr, i, n);
    }
    int size = n;
    while (size > 1) {
        swap(arr, 0, --size);
        heapify(arr, 0, size);
    }
}

基数排序

前面几种都基于比较，复杂度下界是 O(n log n)。基数排序不比较，按个位、十位、百位依次做计数分配， 每一轮 O(n)，轮数等于最大值的位数。代价是只能处理整数这类能拆成「位」的数据。

两个细节：负数先整体减去最小值，挪到非负再排，排完加回来；如果最大值减最小值会超出 int，就要换成 long。 每一轮用前缀和算出每个桶的右边界，再从右往左把数放回去，这样同一个桶里的数保持上一轮的顺序，下一轮才不会把上一轮的结果打乱。 

public static int BASE = 10;
public static int[] cnts = new int[BASE];

// 基数排序：先整体减去最小值把负数挪成非负，再按个位、十位……依次做稳定的计数分配
public static void radixSort(int[] arr) {
    int n = arr.length;
    if (n < 2) {
        return;
    }
    int min = arr[0];
    for (int v : arr) min = Math.min(min, v);
    int max = 0;
    for (int i = 0; i < n; i++) {
        arr[i] -= min;
        max = Math.max(max, arr[i]);
    }
    // max 有几位，就做几轮
    int bits = 0;
    do {
        bits++;
        max /= BASE;
    } while (max > 0);
    for (int offset = 1; bits > 0; offset *= BASE, bits--) {
        Arrays.fill(cnts, 0);
        for (int i = 0; i < n; i++) cnts[(arr[i] / offset) % BASE]++;
        for (int i = 1; i < BASE; i++) cnts[i] += cnts[i - 1];   // 前缀和 = 每个桶的右边界
        for (int i = n - 1; i >= 0; i--) {                       // 从右往左放，保证稳定
            help[--cnts[(arr[i] / offset) % BASE]] = arr[i];
        }
        System.arraycopy(help, 0, arr, 0, n);
    }
    for (int i = 0; i < n; i++) {
        arr[i] += min;
    }
}

怎么选

算法时间额外空间稳定
选择排序O(n²)O(1)否
冒泡排序O(n²)O(1)是
插入排序O(n²)O(1)是
归并排序O(n log n)O(n)是
随机快排O(n log n)（期望）O(log n)否
堆排序O(n log n)O(1)否
计数 / 基数排序O(n)（位数视为常数）O(n + 桶数)是

基于比较、O(n log n)、额外空间低于 O(n)、还稳定，四个条件同时满足的排序目前没有。所以选哪个取决于你在乎哪个： 数据量很小用插入排序；要快、不在乎稳定性用随机快排；要稳定、不在乎多一倍空间用归并；空间必须 O(1) 用堆排序； 值域明确的整数用基数排序。稳定性只对带附加信息的对象有意义，比如按分数排序后同分的人还要保持报名顺序，对纯 int 数组没有区别。

对数器

写完一个排序很难靠肉眼确认它对。对数器的做法很朴素：随机生成大量小数据，用一个肯定正确的方法算出标准答案， 和自己的实现逐个比，第一次不一致时把输入打印出来，拿这组小数据去调。后面的图论和贪心两篇也全部靠它验证。 

// 对数器：随机造数据，拿一个绝对正确的方法（这里是 Arrays.sort）对答案
public static void main(String[] args) {
    Random r = new Random(2026);
    int testTimes = 20000, maxLen = 60, maxVal = 1000;
    for (int t = 0; t < testTimes; t++) {
        int n = r.nextInt(maxLen + 1);
        int[] arr = new int[n];
        for (int i = 0; i < n; i++) {
            arr[i] = r.nextInt(2 * maxVal + 1) - maxVal;   // 带负数
        }
        int[] ans = arr.clone();
        Arrays.sort(ans);
        int[] a1 = arr.clone(); insertionSort(a1);
        int[] a2 = arr.clone(); if (n > 0) mergeSort(a2, 0, n - 1);
        int[] a3 = arr.clone(); if (n > 0) quickSort(a3, 0, n - 1);
        int[] a4 = arr.clone(); heapSort(a4);
        int[] a5 = arr.clone(); radixSort(a5);
        if (!Arrays.equals(ans, a1) || !Arrays.equals(ans, a2) || !Arrays.equals(ans, a3)
                || !Arrays.equals(ans, a4) || !Arrays.equals(ans, a5)) {
            System.out.println("出错了：" + Arrays.toString(arr));
            return;
        }
        // 逆序对：和 O(n^2) 暴力比
        long brute = 0;
        for (int i = 0; i < n; i++) for (int j = i + 1; j < n; j++) if (arr[i] > arr[j]) brute++;
        if (n > 0 && inversions(arr.clone(), 0, n - 1) != brute) {
            System.out.println("逆序对出错：" + Arrays.toString(arr));
            return;
        }
        // 随机选择：和排序后的 ans[k] 比
        if (n > 0) {
            int k = r.nextInt(n);
            if (randomizedSelect(arr.clone(), k) != ans[k]) {
                System.out.println("随机选择出错：" + Arrays.toString(arr));
                return;
            }
        }
    }
    System.out.println("测试通过");
}
