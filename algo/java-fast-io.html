Java 刷题：高效输入输出与空间复用

Java · 刷题模板 ｜ 写于 2026.10
BufferedReader · StreamTokenizer · PrintWriter · 静态数组

在 ACM 模式下用 Java 刷题，算法写对了也可能因为读写太慢或者内存开销太大超时。 这篇用同一道题对比几种写法，最后整理成一份统一模板。

题目：多组矩阵求和

第一行是数据组数；每组先给行数 n 和列数 m，接着是 n 行、每行 m 个整数。每组输出矩阵元素之和。

输入

3
4 3
1 2 3
4 5 6
7 8 9
2 5 8
1 1
5
2 2
3 3
4 4
  • 第 1 行 3：一共 3 组。
  • 第一组 4 3：4 行 3 列，后面 4 行是矩阵（最后一行是 2 5 8）。
  • 第二组 1 1：1 行 1 列，矩阵只有 5。
  • 第三组 2 2：2 行 2 列。

输出（每组矩阵元素之和）

60
5
14

一、高效输入输出

1. Scanner + System.out 低效

import java.util.Scanner;

public class Main {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);
        int t = sc.nextInt();
        for (int k = 0; k < t; k++) {
            int n = sc.nextInt();
            int m = sc.nextInt();
            int[][] mat = new int[n][m];
            for (int i = 0; i < n; i++) {
                for (int j = 0; j < m; j++) {
                    mat[i][j] = sc.nextInt();
                }
            }
            System.out.println(sum(mat, n, m));
        }
        sc.close();
    }

    public static int sum(int[][] mat, int n, int m) {
        int ans = 0;
        for (int i = 0; i < n; i++) {
            for (int j = 0; j < m; j++) {
                ans += mat[i][j];
            }
        }
        return ans;
    }
}

2. BufferedReader + StreamTokenizer + PrintWriter 高效

import java.io.*;

public class Main {
    public static int MAXN = 101;
    public static int MAXM = 101;
    public static int[][] mat = new int[MAXN][MAXM];
    public static int n, m;

    public static void main(String[] args) throws IOException {
        BufferedReader br = new BufferedReader(new InputStreamReader(System.in));
        StreamTokenizer in = new StreamTokenizer(br);
        PrintWriter out = new PrintWriter(new OutputStreamWriter(System.out));
        in.nextToken();
        int t = (int) in.nval;
        for (int k = 0; k < t; k++) {
            in.nextToken();
            n = (int) in.nval;
            in.nextToken();
            m = (int) in.nval;
            for (int i = 0; i < n; i++) {
                for (int j = 0; j < m; j++) {
                    in.nextToken();
                    mat[i][j] = (int) in.nval;
                }
            }
            out.println(sum());
        }
        out.flush();
        out.close();
        br.close();
    }

    public static int sum() {
        int ans = 0;
        for (int i = 0; i < n; i++) {
            for (int j = 0; j < m; j++) {
                ans += mat[i][j];
            }
        }
        return ans;
    }
}

3. BufferedReader 按行读 + PrintWriter 高效

import java.io.*;

public class Main {
    public static int MAXN = 101;
    public static int MAXM = 101;
    public static long[][] mat = new long[MAXN][MAXM];
    public static int n, m;

    public static void main(String[] args) throws IOException {
        BufferedReader br = new BufferedReader(new InputStreamReader(System.in));
        PrintWriter out = new PrintWriter(new OutputStreamWriter(System.out));
        int t = Integer.parseInt(br.readLine().trim());
        for (int k = 0; k < t; k++) {
            String[] nm = br.readLine().trim().split(" +");
            n = Integer.parseInt(nm[0]);
            m = Integer.parseInt(nm[1]);
            for (int i = 0; i < n; i++) {
                String[] row = br.readLine().trim().split(" +");
                for (int j = 0; j < m; j++) {
                    mat[i][j] = Long.parseLong(row[j]);
                }
            }
            out.println(sum());
        }
        out.flush();
        out.close();
        br.close();
    }

    public static long sum() {
        long ans = 0;
        for (int i = 0; i < n; i++) {
            for (int j = 0; j < m; j++) {
                ans += mat[i][j];
            }
        }
        return ans;
    }
}

差别在哪

Scanner 每次 nextInt() 都要做一次正则匹配，数据量到十万、百万级别时会明显变慢。

StreamTokenizer 直接在缓冲字符流上切 token，数字解析好放进 nval；PrintWriter 先把输出写进缓冲区，最后统一 flush()，比逐行打印快得多。

什么时候用第 3 种：nval 是 double，超过 253 的整数会丢精度，读字符串也不方便。数值可能超出这个范围（比如 long 的大数）或者要读字符串时，就按行读，再自己 parseLong / split。

二、空间高效

大空间用全局静态空间，复用数组，不要频繁申请。

1. 临时动态空间 低效

import java.io.*;
import java.util.ArrayList;
import java.util.List;

public class Main {
    public static void main(String[] args) throws IOException {
        BufferedReader br = new BufferedReader(new InputStreamReader(System.in));
        StreamTokenizer in = new StreamTokenizer(br);
        PrintWriter out = new PrintWriter(new OutputStreamWriter(System.out));
        in.nextToken();
        int t = (int) in.nval;
        for (int k = 0; k < t; k++) {
            in.nextToken();
            int n = (int) in.nval;
            in.nextToken();
            int m = (int) in.nval;
            List<List<Integer>> mat = new ArrayList<>();
            for (int i = 0; i < n; i++) {
                List<Integer> row = new ArrayList<>();
                for (int j = 0; j < m; j++) {
                    in.nextToken();
                    row.add((int) in.nval);
                }
                mat.add(row);
            }
            out.println(sum(mat, n, m));
        }
        out.flush();
        out.close();
        br.close();
    }

    public static int sum(List<List<Integer>> mat, int n, int m) {
        int ans = 0;
        for (int i = 0; i < n; i++) {
            List<Integer> row = mat.get(i);
            for (int j = 0; j < m; j++) {
                ans += row.get(j);
            }
        }
        return ans;
    }
}

低效写法每组数据都新建一批 ArrayList，每个元素还要装箱成 Integer； 高效写法按题目上限一次性开好 int[][]，每组只用前 n 行 m 列，空间只申请一次。

三、刷题统一模板

import java.io.*;

public class Main {
    public static int MAXN = 100001;
    public static int[] arr = new int[MAXN];
    public static int n;

    public static void main(String[] args) throws IOException {
        BufferedReader br = new BufferedReader(new InputStreamReader(System.in));
        StreamTokenizer in = new StreamTokenizer(br);
        PrintWriter out = new PrintWriter(new OutputStreamWriter(System.out));
        while (in.nextToken() != StreamTokenizer.TT_EOF) {
            n = (int) in.nval;
            for (int i = 0; i < n; i++) {
                in.nextToken();
                arr[i] = (int) in.nval;
            }
            out.println(compute());
        }
        out.flush();
        out.close();
        br.close();
    }

    public static int compute() {
        int ans = 0;
        for (int i = 0; i < n; i++) {
            ans += arr[i];
        }
        return ans;
    }
}

这个模板不读组数，一直读到输入结束（TT_EOF）。题目先给组数时，就按一、2 或二、2 的写法来。
